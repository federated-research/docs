# Create a TRE


## Prerequisites

- Ensure the Submission Layer has been configured with a Keycloak realm administrator by following the [Add Realm Admin guide](/submission/guides/addrealmadmin).
- Create a TRE administrator user with the `dare-tre-admin` role following the [Add a New User to KeyCloak](/submission/guides/keycloakAdminAddingNewUser) guide.

## Submission Layer Setup

<Steps>

### Create a TRE

1. In the Submission Layer navigate to **TRE → Create new TRE**.
2. Enter the name of the TRE.
3. Enter the username of the TRE administrator created in Keycloak with the `dare-tre-admin` role.
4. Select **Submit**.

During creation, the Submission Layer automatically:

- Creates a dedicated Keycloak client for the TRE.
- Enables a service account for the client.
- Assigns the `dare-tre-admin` role to the service account.
- Stores the generated credentials securely in Vault.
