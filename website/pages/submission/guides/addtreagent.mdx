# Connect a TRE Agent to the Submission Layer

This guide describes how to connect a TRE Agent to the Submission Layer using the **TRE onboarding configuration**. During onboarding, the Submission Layer automatically creates a dedicated Keycloak service account for the TRE and generates a configuration file that the TRE Agent can import.

## Prerequisites

Before creating a TRE, ensure the Submission Layer has been configured with a Keycloak realm administrator by following the [Add Realm Admin guide](/submission/guides/addrealmadmin).

## Submission Layer Setup

<Steps>

### Create a TRE

1. Navigate to **TRE → Create new TRE**.
2. Enter the name of the TRE.
3. Assign a TRE administrator.
4. Select **Submit**.

During creation, the Submission Layer automatically:

- Creates a dedicated Keycloak client for the TRE.
- Enables a service account for the client.
- Assigns the `dare-tre-admin` role to the service account.
- Stores the generated credentials securely in Vault.

### Create a Project

Create a project, assign the TRE and users by following the [Project Setup guide](/submission/guides/submissionManagerSetupNewProject).
