#  Pooled Pattern
|||
|-|-|

| [Egress](../egress) | [Manual](../egress#full-local-control)
| Required Trust between TREs | Very High  

In the pooled pattern row level data moves, either persistently or temporarily, to perform an analysis.
Outside of TREs this is the most common method, where researchers would be accustomed to data being on their computer, where they can perform any analysis or learning. 

This approach requires a very high level of trust between TREs as it requires sharing of row-level data. Disclosure control is still applied before the data leaves the TRE network.

## Variance in implementation
[An emerging implementation](https://zenodo.org/records/10055358) from the [DARE UK TREvolution programme](https://dareuk.org.uk/trevolution/) is that a project-specific network is created between the TREs, to either move the data or provide the researcher with a view of the data that makes it appear as if the data is all in one location. This approach is by far the most powerful for a user and the available analyses are almost unlimited.
