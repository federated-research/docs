
#  Pooled Pattern
**Analytical:** Centralised   
**Data Movement**: Row level data   
**Required Trust between TREs**: Very High   

The pattern captures the movement of data where row level data moves, either persistently or temporarily to perform an analysis. Outside of TREs this is the most common method, where researchers would be accustomed to data being on their data where they can perform any analysis or learning. 

This approach requires a very high level of trust between TREs as it requires sharing of row-level data between TREs. Disclosure control is still applied before the data leaves the TRE network.

## Variance in implementation
An emerging pattern from the DARE UK TREvolution programme is that a project-specific network is created between the TREs, to either move or provide the researcher with a view of the data that makes it appear as if the data is all in one location. This approach is by far the most powerful for a user and the analyses and learning are almost unlimited.
