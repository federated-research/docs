# Traditional Pattern
**Analytical:** Isolated <br/>
**Data Movement**: Summary <br/>
**Required Trust between TREs**: Low <br/>

The most common method of federated analytics carries out a local computation in each location separately to generate summary results which are combined centrally. This pattern requires the lowest trust between TREs, as each result is undertaken independently. 

One limitation of this approach is that data cannot be linked, as no row-level attributes are shared. Certain analyses cannot be undertaken via this method. Though this is the most traditional approach, it is the least powerful of the three patterns for a researcher. 

The analyses that can be run within the boundary of the TRE are almost unlimited and constrained by the compute and permissions from the TRE. The key concept is that manual disclosure control is applied and therefore the results that can then be analysed together are limited.

## Analyses 
An algorithm to calculate a statistic is *isolated* if the algorithm can be broken into subproblems that can be calculated separately at each TRE. These results can be combined to achieve the same result as calculating them on a single, pooled data set.

There are often several different algorithms that can be used to calculate the same statistic, but it is the algorithm, not the statistic which is of importance in determining how it can be federated. In considering several common statistics and algorithms in health informatics, we have produced a table which shows statistics that are known to be calculable in a federated manner using Five Safes TES. Note that this summary gives no regard to disclosure risks or checking of outputs, only the suitability of Five Safes TES for an implementation. This table is not comprehensive, and only encompasses some common analyses in health informatics.

| -------------------------------------- |  ------------------------------------------------------------------------------------ |
| Minimum/maximum                         |                                                                                      |
| Counts                                 | Includes prevalence, incidence                                                       |
| Contingency tables                     | Includes comorbidity. Can be used for Chi-squared test, Fisher's exact test, etc.    |
| Mean                                   |                                                                                      |
| Variance                               | Can be used to calculate standard deviation                                          |
| Covariance                             |                                                                                      |
| Product-moment correlation coefficient | Also known as Pearson's correlation coefficient. Can be used to calculate Fisher's Z |
| t-tests                                | Including one-sample and two-sample t-tests                                          |
| Hotelling's T2                         |                                                                                      |
| ANOVA                                  |                                                                                      |
| t-digest                               | Used to estimate quartiles (median, interquartile ranges, etc.)                      |
