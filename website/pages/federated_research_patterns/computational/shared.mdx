# Shared Pattern
|||
|-|-|
| [Analytical](../computational#analytical-patterns) | Connected  
| [Data Movement](../computational#data-movement-patterns) | Model parameters or summary 
| Required Trust between TREs | High  

This is the most common method for federated learning, but can also be used for analytics that cannot be isolated, for example finding the median by binary search.
In a Shared pattern, some computation is carried out in each TRE and model parameters or a summary is sent back to the central node, which redistributes some of this information back to the TREs.
Higher trust is required between the TREs as results are combined and shared between other TREs whom they must trust with this information.
