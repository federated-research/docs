# Weaves

A **Weave** brings together an [Interface](/federated_research_patterns/interface), a [Computational Pattern](/federated_research_patterns/computational) and an [Egress Inspection Pattern](/federated_research_patterns/egress) into a single entity. Each on its own describes one aspect of a federated approach: the Interface captures what is **possible**, the Egress Inspection Pattern captures what is **acceptable**, through how results are checked before they move, and the Computational Pattern captures what is **useful**, through which analyses a researcher can carry out. A Weave combines them so that an approach can be assessed across all three aspects together, rather than one at a time.

## Creating a Weave

A Weave must contain a single Interface, a single Computational Pattern and a single Egress Inspection Pattern. A single platform may have multiple Weaves if it implements more than one Computational Pattern, or supports more than one Egress Inspection Pattern.
