# Weaves

A **Weave** brings together an [Interface](/federated_research_patterns/interface), a [Computational Pattern](/federated_research_patterns/computational) and an [Egress Inspection Pattern](/federated_research_patterns/egress) into a single entity. Each on its own describes part of a federated approach: the interface captures what is possible, and the computational and egress inspection patterns together capture what is acceptable, through what moves between TREs and how it is checked. A Weave combines them so the usefulness of that combination for researchers can be assessed as a whole.

## Creating a Weave

A Weave must contain a single Interface, a single Computational Pattern and a single Egress Inspection Pattern. A single platform may have multiple Weaves if it implements more than one Computational Pattern, or supports more than one Egress Inspection Pattern.
