# Weaves

A **Weave** is a combination of a platform and computational pattern, which are linked by what disclosure control is allowed for that Weave.

## Creating a Weave

A Weave must contain a single [Platform Pattern](/federated_research_patterns/platforms) and a single [Computational Pattern](/federated_research_patterns/computational). A single platform may have multiple Weaves if it implements more than a single Computational Pattern.
